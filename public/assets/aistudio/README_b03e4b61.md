# Trade Meds

A React + Vite + TypeScript frontend starter for a medical apparel e-commerce storefront inspired by the shopping experience of Knya, with original Trade Meds branding.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Included
- Responsive storefront homepage
- Shop page with category filtering, search and sorting
- Product detail pages with size and colour selection
- Cart with quantity controls and LocalStorage persistence
- Wishlist with LocalStorage persistence
- Demo account page
- Mobile navigation
- Trade Meds branding

## Important notes
- Product names, prices, ratings and inventory are sample demonstration data.
- Product photography currently uses remote Unsplash image URLs and requires an internet connection.
- Checkout, payment processing, real authentication, inventory and order management are not connected.
- This is an original starter implementation, not a pixel-perfect copy of Knya. Replace demo assets and content with assets you own or are licensed to use before production.
